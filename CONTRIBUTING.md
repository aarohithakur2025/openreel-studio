# Contributing

1. Open an issue for a bug or feature before large changes.
2. Keep changes small and testable.
3. Run `python -m compileall tools` and `python tools/validate_repo.py`.
4. Never add secrets, credentials, model weights, generated media, or private repository content.
5. Keep the ComfyUI API contract explicit; do not silently convert malformed workflows.
6. Pull requests should explain what was tested.
